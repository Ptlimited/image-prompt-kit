# When the image misses

Send the fix as a follow up message in the same chat. 1 change per message. Say what changes and what stays.

| What went wrong | Send this |
|---|---|
| The face drifted | "Keep their face exactly the same as the photo. Change only the clothes." |
| A word is misspelled | "The headline must read exactly "YOUR WORDS". Change only the headline. Keep everything else the same." |
| Small print looks like gibberish | Only the big words are reliable. In the tests, the headlines came out right and the tiny columns of text did not. Keep the exact words to a headline or two, and let the rest be texture. |
| It added words you did not ask for | ChatGPT: add "no extra text, no logos, no watermark". Nano Banana: say what you want instead ("a clean blank wall"), since Google's guide prefers positive wording. |
| It looks too plastic or too polished | ChatGPT: say "real photograph" and drop heavy grading words. Nano Banana: name a lens and a light ("35mm lens at f/1.8, soft window light, natural skin texture"). |
| Wrong shape | Pick the aspect ratio in the tool's settings, and end the prompt with "Make it a vertical 4:5 image." |
| 1 detail is off, the rest is good | "Make the jacket red. Keep the rest exactly the same." |
| Later edits start to drift | Repeat what has to stay: "Keep the person, pose and lighting the same." |

Sources are in `gemini.md` and `chatgpt.md`.
